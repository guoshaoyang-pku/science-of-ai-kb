# Contributing

Run setup.sh, activate .venv, and use [AGENTS.md](AGENTS.md). Preserve source layout and use nearby tests. Avoid unrelated refactors and dependencies.

Bug reports should include a sanitized reproduction, Python/OS/CLI versions and error. Do not attach keys, CLI homes, session logs or final test prompts. Scientific claims need controls, paired seeds, measurements, uncertainty, counterexamples and limits.

Open a branch and pull request describing changes and checks. Distinguish saved-output verification from new model calls or training. Codex and Claude Code contributors share the visibility and provenance rules.
