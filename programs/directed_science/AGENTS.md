# Directed Science

Read README.md, HANDOFF.md and the direction handoffs. Current studies are complete; wait for a new objective before new research.

- Use Python from the installed environment; NumPy, Torch, SciPy and Matplotlib.
- Sources and successful measurements are immutable development evidence. New predictions require new prospective conditions.
- Use the saved executors and contracts; one worker per study, torch threads=1.
- Recompute analysis in a temporary copy; never overwrite training results.
- A report may explain multiple short claims and keep competing explanations and failures.
- origin_iteration attributes research; application time is distinct. No strict topic cap.
- Science/OOD success and solver score need separate measurements. No solver gain is measured in this program.
- Coordinate shared KB/Git edits; preserve concurrent changes.
